# BREAKOUT

A game reminiscent of the of the <a href=https://en.wikipedia.org/wiki/Breakout_(video_game)">1976 action video game</a> on ATARI. Only now with a little twist.

I plan on completing further designs and creating new stages with better levels, unique sounds, and a scoreboard for points. 

Current schedule for the project is halted due to other competing priorities. Enjoy the game at current state. Once my framework is completed I will be "breaking out" my framework for the project vs the break style game so that it will be easier for other to follow along with.
